# CURRENCIES

An international currency exchange-rate widget for OmaLauncher.

Track currencies worldwide with country flags, daily reference rates, movement arrows, customisable favourites and a built-in currency converter.

## Features

- Worldwide currency selection with searchable names and ISO codes
- Customisable base currency and favourites
- Green and red arrows comparing successive published rates
- Built-in amount converter
- Offline access to previously saved rates
- Automatic exchange-rate refresh
- Source dates shown alongside rates
- Dark/light theme support

## Defaults

- Base currency: GBP
- Favourites: TRY, EUR, USD, CNY
- Widget size: 3x2
- Minimum size: 2x2

Users can change their selections at any time.

## Data and privacy

Exchange rates are provided by Frankfurter:
https://frankfurter.dev/

Rates are reference rates, not live trading or bank rates.

No account, API key, GPS access or location permission is required. No additional Linux packages are needed.

## Compatibility

Requires OmaLauncher with OWL 11 or newer.
