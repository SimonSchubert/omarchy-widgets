# Tempo por hora / Hourly weather

A one-row weather widget with a Portuguese configuration screen. Resize its width to show more consecutive hours. The current time stays on the left, highlighted; each forecast includes a day/night weather icon, temperature in Celsius and precipitation probability.

Tap the tile, enter a city, optionally filter by country (name or ISO code) and state/region (full name), then select a matching location. The selection persists. Times follow the selected city's time zone; forecasts refresh every 20 minutes while the widget is active.

The percentage means **chance of precipitation**, not confidence in the overall forecast. Weather conditions are grouped into nine icon categories, with day/night variants where available. An internet connection is required. No API key, Linux packages or location permission is needed.

Data: [Open-Meteo](https://open-meteo.com/) and [GeoNames](https://www.geonames.org/), via Open-Meteo's geocoding API.

## Português

Toque no widget para configurar país, estado e cidade. País e estado são filtros opcionais; após buscar, toque na cidade correta. Aumente a largura para ver mais horas. O primeiro horário é o atual no fuso da cidade escolhida. A porcentagem indica chance de chuva.
