# Glass Happiness tank

The [Glass Happiness](../../../apps/blankplusblank/glass-happiness) terrarium on home: the tank, the sky and weather in its window, and each plant's root moisture against its sweet spot. It sends a notification when a plant gets thirsty. Tap it to open the app and tend the tank.

**For reviewers:** this widget has the app's Perl sim and feed scripts inside it too, so it can run the tank on its own. When both are open, the feed's lock lets one copy run the sim and the other watch its frames. It reads and writes the same files as the app, under `~/.local/share/mossglass/` and `~/.cache/mossglass/`.
