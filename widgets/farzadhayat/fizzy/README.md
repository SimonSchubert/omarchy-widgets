# fizzy

Your open [Fizzy](https://fizzy.do) cards on the home screen, newest activity first.

- Tile: cards with board, column and age; tap a card to open it, tap the header area to open the full-screen view.
- Full-screen view: board chips, a "mine" filter, column chips for the picked board, a ✓ to close a card (with undo), and an input to add a card to the picked board.
- Setup: type a Fizzy personal access token (profile > API; read + write to close and add cards) on the tile. It is kept encrypted on the phone and never stored in the file.
- Needs no Linux packages: it only makes web requests to app.fizzy.do. Only the first page of cards Fizzy returns is shown.
