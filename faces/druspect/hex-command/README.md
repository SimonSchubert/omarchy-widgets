# Hex Command

Thank you for taking a look at Hex Command. It is a full-page Omalauncher face that combines a theme-aware system dashboard with a movable hexagonal launcher for the apps you use most.

## Highlights

- Adapts its glass, borders, indicators and accents to the active Omarchy theme.
- Shows weather, battery, memory, storage, CPU, display and thermal information in a compact command deck.
- Ranks apps using Omalauncher's own recency and usage scores.
- Filters common banking apps and Java runtime utilities from the glanceable app field.
- Moves the hex matrix as one controlled surface; drag a tile or the space between tiles.
- Keeps narrow side gutters available for normal home-page swipes.
- Long-press the app field to recenter it.

## Data and privacy

The face runs no shell commands and installs no packages. Weather is requested from `https://wttr.in/?format=j1`, which chooses an approximate location from the network request; no coordinates, account details or API keys are stored in the face.

The notification source is used only to display the local notification count. Notification contents are not rendered, written to disk or sent anywhere. App names, icons and usage scores stay inside Omalauncher and are used only to build the local ranking.

## Compatibility

Hex Command requires OWL 11 (Omalauncher 0.10.0 or newer). It is designed for phone-sized portrait faces and remains theme-relative, including on light themes.

I hope it makes your home screen feel both useful and distinctly yours. Suggestions and thoughtful review are very welcome.
