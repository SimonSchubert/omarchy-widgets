# app browser

A full home-page face for browsing the phone's apps. It lists everything the launcher's drawer knows about, with a search field, categories by app kind and work profile, and folders for favorites, work, talk, media, tools, Linux apps and OWL apps.

Long-press an app to add it to favorites or use its drawer actions. The favorites list, the rail state and the icon density are kept on the device; nothing is sent anywhere. The face runs no shell commands and needs no packages.
